# 🎨 Pixel Art Animator

A browser-based pixel art editor with frame-by-frame animation, built using **vanilla JavaScript** and the **Canvas API** — no frameworks, no dependencies.

🔗 **Live Demo:** [https://saimali35.github.io/pixel-art-animator/](https://saimali35.github.io/pixel-art-animator/)

---

## ✨ Features

- 🖌 **Draw** on a 32×32 pixel grid with a color picker
- 🧹 **Eraser** tool to remove pixels
- 📐 **Brush sizes** — 1×1, 2×2, 3×3
- ↩ **Undo** support (up to 30 steps)
- 🗑 **Clear frame** with one click
- 🖼 **Multiple frames** — add, duplicate, delete
- ▶ **Animate** frames with adjustable speed (ms)
- 👻 **Onion skinning** — see a ghost of the previous frame while drawing
- ⬇ **Export as GIF** — animated GIF download (pure JS, no library)
- ⬇ **Export as Sprite Sheet** — all frames in one PNG
- 💾 **Save Project** — download your work as JSON
- 📂 **Load Project** — reload a saved JSON project
- 🖼 **Import Image**  — import your image 
- 📱 **Mobile responsive** — works on phones with touch drawing support

## 🚀 How to Run Locally

```bash
git clone https://github.com/saimali1254/pixel-art-animator.git
cd pixel-art-animator
```

Then open `index.html` with **Live Server** in VS Code — or just double click the file.

## 🎮 How to Use

1. Pick a color from the color picker
2. Click or drag on the canvas to draw
3. Add more frames using **+ Add** in the sidebar
4. Press **▶ Play** to preview the animation
5. Enable **Onion Skin** to see the previous frame while drawing
6. Click **⬇ Export GIF** to download your animation
